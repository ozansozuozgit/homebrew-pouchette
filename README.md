# homebrew-pouchette

Official Homebrew tap for [Pouchette](https://pouchette.com) — on-device meeting and lecture
memory for the Mac. No bot joins your call, no account, and every answer cites the moment it
was said.

## Install

```sh
brew install --cask ozansozuozgit/pouchette/pouchette
```

Requires macOS 14+ on Apple Silicon. The app updates itself via Sparkle after install
(`auto_updates true`), so `brew upgrade` is only needed if you prefer Homebrew-managed updates.

## About this tap

This tap is maintained by the Pouchette team and updated with each release. Issues with the
*app* go to ozansozuoz@gmail.com — this repo only tracks the cask.
